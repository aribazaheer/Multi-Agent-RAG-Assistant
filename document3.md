# Multi-Agent Systems

A multi-agent system consists of multiple AI agents that work together
to accomplish a larger task.

Each agent can have a specialized role. For example, one agent can
perform research, another can verify information, and another can
write the final response.

Multi-agent orchestration allows complex workflows to be divided into
smaller specialized tasks.

CrewAI and LangGraph are examples of frameworks that can be used to
build and orchestrate agentic workflows.
